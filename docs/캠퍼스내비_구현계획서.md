## 1. 개발 로드맵

### Phase 1 (1개월): MVP 안정화
**목표:** 보안 패치 + 기본 기능 안정화

**모듈:**
1. LoginServlet DB 연동
2. SQL Injection 패치 (Prepared Statement)
3. HTTPS/SSL 적용
4. 기본 에러 처리 강화

**산출물:**
- 보안 패치 완료 코드
- 테스트 결과 보고서

---

### Phase 2 (3개월): 핵심 기능
**목표:** 기획서 핵심 기능 구현

**모듈:**
1. Naver Map API 통합 (실내 네비게이션)
2. AI 추천 시스템 (협력 필터링)
3. 관리자 대시보드
4. 예약 승인 시스템

---

### Phase 3 (6개월): 고도화
**목표:** 성능 최적화 + CI/CD 구축

**모듈:**
1. REST API 개발
2. Docker 컨테이너화
3. CI/CD 파이프라인 (Jenkins/GitHub Actions)
4. 모니터링 시스템 구축

---

### Phase 4 (12개월+): 플랫폼화
**목표:** 다중 캠퍼스 지원

**모듈:**
1. Spring Framework 마이그레이션
2. 생성형 AI 활용 (자연어 검색)
3. 모바일 앱 개발
4. 다중 캠퍼스 지원
