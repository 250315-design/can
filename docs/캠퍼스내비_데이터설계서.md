## 2. 테이블 설계

### 2.1 users (사용자)
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    userid VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,    -- 하드코딩, 개선: bcrypt
    name VARCHAR(100) NOT NULL,
    role ENUM('student','assistant','professor','admin','guest','visitor'),
    dept VARCHAR(100),
    email VARCHAR(100),
    phone VARCHAR(20),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2.2 assets (자산) - 8,401개
```sql
CREATE TABLE assets (
    id INT PRIMARY KEY AUTO_INCREMENT,
    asset_no VARCHAR(50) UNIQUE NOT NULL,
    item_name VARCHAR(200) NOT NULL,
    asset_class VARCHAR(100),     -- 자산 분류
    category_sub1 VARCHAR(100),   -- 세부 카테고리
    category_sub2 VARCHAR(100),
    location VARCHAR(200),        -- 위치
    detail_location VARCHAR(500), -- 상세 위치
    floor INT,                    -- 층수
    latitude DECIMAL(10,8),       -- 위도 (향후 사용)
    longitude DECIMAL(11,8),      -- 경도 (향후 사용)
    manage_dept VARCHAR(100),     -- 관리 부서
    manager_name VARCHAR(100),    -- 담당자
    manager_phone VARCHAR(20),
    asset_status ENUM('사용중','예약됨','사용불가','폐기'),
    description TEXT,
    quantity INT DEFAULT 1,
    purchase_date DATE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    KEY (item_name),
    KEY (category_sub1),
    KEY (asset_status),
    KEY (floor)
);
```

### 2.3 reservations (예약)
```sql
CREATE TABLE reservations (
    id INT PRIMARY KEY AUTO_INCREMENT,
    asset_no VARCHAR(50) NOT NULL,
    user_id INT NOT NULL,
    reserve_date DATE NOT NULL,
    start_time TIME NOT NULL,
    end_time TIME NOT NULL,
    purpose VARCHAR(500),
    status ENUM('pending','approved','rejected','cancelled') DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (asset_no) REFERENCES assets(asset_no),
    FOREIGN KEY (user_id) REFERENCES users(id),
    KEY (asset_no, reserve_date),
    UNIQUE KEY unique_reservation (asset_no, reserve_date, start_time, end_time)
);
```

### 2.4 asset_transfer (자산 이관) - 141건
```sql
CREATE TABLE asset_transfer (
    id INT PRIMARY KEY AUTO_INCREMENT,
    asset_no VARCHAR(50) NOT NULL,
    transfer_date DATE NOT NULL,
    before_dept VARCHAR(100),
    after_dept VARCHAR(100),
    before_location VARCHAR(200),
    after_location VARCHAR(200),
    remarks TEXT,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (asset_no) REFERENCES assets(asset_no),
    KEY (asset_no)
);
```

### 2.5 asset_disposal (자산 폐기) - 2,721건
```sql
CREATE TABLE asset_disposal (
    id INT PRIMARY KEY AUTO_INCREMENT,
    asset_no VARCHAR(50) NOT NULL,
    disposal_date DATE NOT NULL,
    disposal_type VARCHAR(100),    -- 폐기 사유
    residual_value INT,           -- 잔존가치
    remarks TEXT,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (asset_no) REFERENCES assets(asset_no)
);
```

### 2.6 professors (교수)
```sql
CREATE TABLE professors (
    id INT PRIMARY KEY AUTO_INCREMENT,
    prof_name VARCHAR(100) NOT NULL,
    dept VARCHAR(100),
    office VARCHAR(200),
    phone VARCHAR(20),
    email VARCHAR(100),
    intro TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2.7 prof_subjects (교수 담당과목)
```sql
CREATE TABLE prof_subjects (
    id INT PRIMARY KEY AUTO_INCREMENT,
    prof_id INT NOT NULL,
    subject_name VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (prof_id) REFERENCES professors(id),
    KEY (prof_id)
);
```

### 2.8 prof_skills (교수 기술/전문분야)
```sql
CREATE TABLE prof_skills (
    id INT PRIMARY KEY AUTO_INCREMENT,
    prof_id INT NOT NULL,
    skill_type VARCHAR(50),        -- 기술, 전공 등
    skill_name VARCHAR(100) NOT NULL,
    skill_level INT DEFAULT 1,    -- 1~5 레벨
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (prof_id) REFERENCES professors(id),
    KEY (prof_id)
);
```

## 4. 데이터 무결성

### 4.1 제약조건

- **PK:** 모든 테이블 id 기본키
- **FK:** 예약, 이관, 폐기 테이블이 assets 참조
- **UNIQUE:** users.userid, assets.asset_no, reservations 복합키

### 4.2 캐스케이드 규칙

- assets 삭제 시: reservations, asset_transfer, asset_disposal 함께 처리
- 향후 개선: 소프트 딜리트 적용 (deleted_at 타임스탬프)
