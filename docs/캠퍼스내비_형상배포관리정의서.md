## 2. CI/CD 파이프라인

### 2.1 현재 상태
- 수동 compile.bat 실행
- 수동 배포

### 2.2 향후 (Phase 3)
- GitHub Actions 또는 Jenkins 도입
- 자동 빌드 및 테스트
- 자동 배포

---

## 3. 빌드 프로세스

### 3.1 현재
```
compile.bat
  └─ javac (Tomcat lib 참조)
      └─ WEB-INF/classes/*.class
```

### 3.2 향후 (Maven)
```
mvn clean package
  └─ pom.xml 기반 의존성 관리
      └─ target/CampusNav.war
```
