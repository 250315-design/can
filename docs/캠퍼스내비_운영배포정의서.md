## 2. 배포 절차

### 2.1 사전 준비
```bash
# 1. Tomcat 중지
shutdown.bat

# 2. 데이터베이스 백업
mysqldump -u root -p1234 campusnav > backup_260527.sql

# 3. 현재 배포본 백업
copy webapps\CampusNav webapps\CampusNav_backup_260527
```

### 2.2 배포
```bash
# 1. 새 WAR 파일 배포
copy CampusNav.war webapps\

# 2. Tomcat 시작
startup.bat

# 3. 헬스 체크
curl http://localhost:8080/CampusNav/campuslogin.jsp
```

### 2.3 검증
- 로그인 기능 확인
- 검색 기능 확인
- 예약 기능 확인
- 에러 로그 확인

## 5. 장애 대응

### 5.1 장애 분류

| 장애 | 원인 | 해결 |
|-----|------|------|
| 로그인 불가 | DB 연결 실패 | MySQL 재시작 |
| 검색 느림 | 인덱스 부족 | 쿼리 최적화 |
| 메모리 부족 | 메모리 누수 | Tomcat 재시작 |
| 500 에러 | 코드 버그 | 로그 확인 후 패치 |

### 5.2 RTO/RPO 목표

```
RTO (복구 시간): 4시간
RPO (데이터 손실): 1시간
```

## 6. 데이터 관리

### 6.1 백업 정책

```
일간 백업: 매일 22:00 (로컬 스토리지)
주간 백업: 매주 일요일 (외부 스토리지)
보관 기간: 3개월
```

### 6.2 복구 절차

```bash
# 1. MySQL 서비스 중지
net stop MySQL80

# 2. 백업 파일 복구
mysql -u root -p1234 campusnav < backup_260527.sql

# 3. MySQL 서비스 시작
net start MySQL80

# 4. 검증
mysql -u root -p1234 -e "SELECT COUNT(*) FROM assets;"
```
