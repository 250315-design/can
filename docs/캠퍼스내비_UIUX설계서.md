## 1. 디자인 시스템

### 1.1 컬러 팔레트 (ppd4 테마)
- **배경:** 흰색 (#FFFFFF)
- **기본:** 파란색 (#1a56db)
- **강조:** 초록색, 빨강색, 주황색
- **텍스트:** 다크 그레이 (#374151)

### 1.2 타이포그래피
- **본문:** DM Sans, Noto Sans KR
- **코드:** DM Mono
- **기본 크기:** 15px

### 1.3 반응형 디자인
- 모바일: 320px 이상
- 태블릿: 768px 이상
- 데스크톱: 1024px 이상

## 2. 주요 페이지 레이아웃

### 2.1 로그인 페이지 (campuslogin.jsp)
- 입력: ID, 비밀번호
- 기능: 빠른 로그인 (학생/조교/교수/관리자/게스트 버튼)
- 링크: 회원가입

### 2.2 메인 페이지 (role별)
- 헤더: 로고, 검색바, 사용자 메뉴
- 사이드바: 메뉴 네비게이션 (역할별)
- 콘텐츠: 역할 맞춤 정보

### 2.3 검색 페이지 (search.jsp)
```
검색바 (키워드)
  ├─ 카테고리 필터
  ├─ 상태 필터
  └─ 정렬 옵션
    ↓
검색 결과 (20개/페이지)
  ├─ 자산 카드
  │  ├─ 이미지
  │  ├─ 자산명
  │  ├─ 위치
  │  └─ 상태
  └─ 페이지네이션
```

### 2.4 상세 페이지 (detail.jsp)
```
자산 정보
  ├─ 이미지
  ├─ 기본정보 (명, 위치, 관리부서, 담당자)
  ├─ 이관 이력 (타임라인)
  └─ 예약 현황 (캘린더)

액션
  ├─ 예약 버튼
  ├─ 공유 버튼
  └─ 문의하기
```

### 2.5 예약 페이지 (reserve.jsp)
```
예약 폼
  ├─ 자산 선택 (이미 선택됨)
  ├─ 날짜 선택
  ├─ 시간대 선택
  ├─ 목적 입력
  └─ 제출 버튼

중복 검사 (AJAX)
  └─ 실시간 가능 시간대 표시
```

### 2.6 관리 페이지 (asset_manage.jsp)
```
자산 목록 (테이블)
  ├─ 검색/필터
  ├─ 자산 행
  │  ├─ ID
  │  ├─ 명칭
  │  ├─ 위치
  │  ├─ 상태
  │  └─ 액션 (수정, 삭제)
  └─ 액션 바
     ├─ 추가 버튼
     └─ 일괄 작업

자산 상세 (모달)
  ├─ 기본정보 편집
  ├─ 이관 기록
  ├─ 폐기 처리
  └─ 저장/취소
```

## 3. 컴포넌트 설계

### 3.1 공통 컴포넌트

| 컴포넌트 | 용도 | 예시 |
|---------|------|------|
| 헤더 | 네비게이션, 검색 | 모든 페이지 상단 |
| 푸터 | 링크, 저작권 | 모든 페이지 하단 |
| 모달 | 확인, 폼 | 삭제, 상세 편집 |
| 카드 | 콘텐츠 표시 | 검색 결과 |
| 테이블 | 데이터 표시 | 관리 페이지 |
| 페이지네이션 | 페이지 이동 | 검색 결과 |

### 3.2 상태 표시

| 상태 | 색상 | 아이콘 |
|-----|------|--------|
| 사용중 | 녹색 | ✓ |
| 예약됨 | 주황색 | ⏱ |
| 사용불가 | 빨강색 | ✕ |
| 폐기 | 회색 | - |

## 4. 사용성 지침

### 4.1 접근성 (A11y)
- 색상만으로 정보 전달 안 함
- 버튼 크기 최소 44x44px
- 폰트 크기 최소 12px
- 대비율 4.5:1 이상 (텍스트)

### 4.2 성능
- 이미지 최적화 (자동 압축)
- 지연 로딩 (Lazy Loading)
- CDN 활용 (부트스트랩, 아이콘)
