## 1. 컴포넌트 간 통신

### 1.1 Servlet ↔ JSP 통신

**LoginServlet → main_*.jsp**
```
Request: POST /login
Body: userid, password

Response: Redirect
Session Attributes:
  - loginUser (int)
  - loginName (String)
  - loginRole (String: student/assistant/professor/admin/guest/visitor)
```

**LogoutServlet → campuslogin.jsp**
```
Request: GET /logout
Response: Redirect + Session Invalidate
```

### 1.2 JSP ↔ Database (JDBC)

**search.jsp → MySQL**
```
SELECT * FROM assets 
WHERE item_name LIKE ? 
  AND category_sub1 = ? 
  AND asset_status = ?
LIMIT 20 OFFSET ?

Response: ResultSet → LinkedHashMap → JSP Template
```

**reserve.jsp → MySQL (중복 검사)**
```
AJAX Request:
  GET /getReservations.jsp?asset_no=...&date=...

Response: JSON
[
  {start_time: "09:00", end_time: "10:00"},
  {start_time: "14:00", end_time: "15:00"}
]
```

**reserve.jsp → MySQL (예약 저장)**
```
INSERT INTO reservations (asset_no, user_id, reserve_date, start_time, end_time, purpose, status)
VALUES (?, ?, ?, ?, ?, ?, 'pending')
```

## 2. API 엔드포인트 정의 (향후 REST API)

### 2.1 인증 API
```
POST /api/auth/login
  Body: {userid, password}
  Response: {token, role, user_info}

POST /api/auth/logout
  Headers: Authorization: Bearer {token}
  Response: {status: "success"}
```

### 2.2 자산 검색 API
```
GET /api/assets/search
  Query: keyword, category, status, floor, page, limit
  Response: {data: [{id, name, location, status}], total, pages}

GET /api/assets/{id}
  Response: {asset_info, reservation_history, current_reservations}
```

### 2.3 예약 API
```
POST /api/reservations
  Body: {asset_id, date, start_time, end_time, purpose}
  Response: {reservation_id, status}

GET /api/reservations/{id}/conflicts
  Query: date, start_time, end_time
  Response: {conflicts: []}

DELETE /api/reservations/{id}
  Response: {status: "cancelled"}
```

## 4. 에러 처리

### 4.1 HTTP 상태코드
- 200: 성공
- 400: 잘못된 요청
- 401: 인증 실패
- 403: 권한 없음
- 404: 리소스 없음
- 500: 서버 오류

### 4.2 에러 메시지 형식
```json
{
  "success": false,
  "error_code": "DUPLICATE_RESERVATION",
  "message": "해당 시간에 이미 예약이 있습니다.",
  "details": "2026-05-27 09:00 ~ 10:00"
}
```
