## 1. 주요 프로세스 플로우

### 1.1 로그인 프로세스
```
사용자 입력 (ID/PW)
    ↓
LoginServlet 검증
    ├─ DB 조회 (개선: 현재 하드코딩)
    ├─ 비밀번호 확인 (bcrypt 도입)
    └─ 세션 생성 (loginUser, loginRole)
    ↓
역할 기반 리다이렉트
    ├─ student → main_student.jsp
    ├─ professor → main_professor.jsp
    ├─ admin → main_admin.jsp
    └─ ...
```

### 1.2 검색 프로세스
```
search.jsp 로드
    ↓
사용자 입력 (키워드, 필터)
    ↓
JDBC 쿼리
    ├─ SELECT * FROM assets WHERE ... LIMIT 20
    ├─ 키워드 AND 카테고리 AND 상태
    └─ 정렬 (기본: 최신순)
    ↓
ResultSet → LinkedHashMap 변환
    ↓
JSP 템플릿 렌더링
    └─ 결과 20개 + 페이지네이션
```

### 1.3 예약 프로세스
```
reserve.jsp 로드
    ↓
AJAX: 중복 예약 검사
    └─ SELECT * FROM reservations WHERE asset_no = ? AND ...
    ↓
사용자 입력 (날짜, 시간, 목적)
    ↓
INSERT INTO reservations
    ├─ asset_no, user_id, date, time
    └─ status = 'pending' (또는 승인 대기)
    ↓
detail.jsp 새로고침
    └─ 예약 현황 업데이트
```

### 1.4 자산 관리 프로세스 (Admin)
```
asset_manage.jsp 로드
    ↓
자산 목록 조회
    └─ SELECT * FROM assets
    ↓
액션 선택
    ├─ 추가 → INSERT
    ├─ 수정 → UPDATE
    └─ 삭제 → DELETE
    ↓
확인/취소
    └─ 변경 사항 DB 저장
```

## 2. 알고리즘 & 비즈니스 로직

### 2.1 중복 예약 검사 알고리즘
```java
SELECT COUNT(*) FROM reservations
WHERE asset_no = ?
  AND reserve_date = ?
  AND (
    (start_time >= ? AND start_time < ?)  // 겹침 1
    OR (end_time > ? AND end_time <= ?)   // 겹침 2
    OR (start_time <= ? AND end_time >= ?) // 포함 3
  )
```

### 2.2 자산 상태 관리 로직
```
상태 전이:
  사용중 → 예약됨 (예약 생성 시)
  사용중 → 사용불가 (장애 발생)
  예약됨 → 사용중 (예약 취소)
  * → 폐기 (폐기 기록 등록)
```

## 3. 데이터 처리 규칙

### 3.1 검색 필터링 순서
1. 키워드 검색 (LIKE 검색)
2. 카테고리 필터링 (=)
3. 상태 필터링 (=)
4. 위치 필터링 (=)
5. 정렬 (ORDER BY)
6. 페이지네이션 (LIMIT, OFFSET)

### 3.2 입력값 검증
- 키워드: 최대 100자, HTML 인코딩
- 날짜: 오늘 이후만 허용
- 시간: HH:MM 형식
- 목적: 최대 500자
