## 1. 비즈니스 환경 분석

### 1.1 고등교육 시장 트렌드

**스마트 캠퍼스 도입 현황:**
- 서울 소재 대학: ~60% (영상, 센서, IoT)
- 지역 대학: ~35% (기본 디지털 인프라)
- 폴리텍: ~20% (산학협력 중심)

**주요 구축 영역:**
1. 실내 네비게이션 (스마트 캠퍼스 필수 요소)
2. 자원 예약 시스템 (강의실, 장비)
3. 이용률 분석 대시보드 (운영 효율화)
4. 모바일 앱 기반 통합 플랫폼

## 3. 유사 시스템 사례 분석

### 3.1 국내 대학 사례

#### KAIST → "KAIST 캠퍼스 맵"
- 자체 개발 (2019~)
- 실내 네비게이션 (AR 지원), 예약 시스템, 분석 대시보드, 모바일 앱
- 배운 점: 초기 데이터 구축 3~6개월 소요, 예산 초기 5억원

#### 직업학교 (유사 규모) → 자체 개발
- JSP + MySQL (2022~)
- 기능: 강의실/실습실 검색, 장비 예약, 교수 정보, 이용률 분석
- 구축: 2개월, 비용 5,000만원 (외주)
