## 1. JSP + 직접 JDBC 구조 선택

**결정:** JSP에서 직접 JDBC 사용

**배경:**
- 기존 구현이 이미 JSP 중심
- 빠른 프로토타입 필요

**대안:**
1. Servlet + JSP 분리 (권장)
2. Spring Framework 도입 (비용 증가)
3. 현 상태 유지 (선택됨)

**결정 근거:**
- 단기 프로토타입에 적합
- 향후 Phase 2에서 Servlet 계층 추가
