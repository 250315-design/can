## 1. 시스템 개요

### 1.1 목표 (Objectives)

**기획서 목표:**
1. 교내 자원 통합 검색 플랫폼 구축
2. 맞춤형 추천 서비스 제공
3. 실내외 연계 네비게이션 기능
4. 데이터 기반 운영 효율 개선

**현재 구현 상태 (v1.0):**
- ✅ 통합 검색 플랫폼 (기본)
- ❌ 맞춤형 추천 (설계 필요)
- ⚠️ 네비게이션 (Placeholder만 존재)
- ❌ 운영 분석 (미구현)

### 1.2 아키텍처 스타일

**현재:** JSP-직접 JDBC 아키텍처 (3-Tier JSP)

```
Presentation Tier: JSP (서버 렌더링)
    ↓
Business Logic: JSP 내 JDBC (미분리)
    ↓
Data Tier: MySQL
```

**문제점:**
- 비즈니스 로직이 JSP에 산재
- 코드 재사용성 낮음
- 테스트 곤란
- 유지보수 어려움

**권장:** Servlet-JSP-JDBC 분리 구조로 점진적 전환

## 2. 시스템 구성 (Components)

### 2.1 Presentation Layer (JSP)

| JSP | 역할 | 담당 기능 |
|-----|------|---------|
| `campuslogin.jsp` | 로그인 | 사용자 인증 |
| `main_student.jsp` | 메인 (학생) | 역할별 메인 페이지 |
| `search.jsp` | 검색 | 자산 검색 |
| `detail.jsp` | 상세 | 자산 상세 정보 |
| `reserve.jsp` | 예약 | 자산 예약 |
| `transfer.jsp` | 이관 | 이관 이력 조회 |
| `professor.jsp` | 교수 | 교수 정보 |
| `asset_manage.jsp` | 관리 | 자산 CRUD |

### 2.2 Application Layer (Servlet)

**활성 서블릿 (web.xml 등록):**
- `LoginServlet` (/login)
- `LogoutServlet` (/logout)
- `GuestServlet` (/guest)
- `VisitorServlet` (/visitor)

**미사용 서블릿 (컴파일되지만 미등록):**
- AssetServlet, SearchServlet, DetailServlet, ReserveServlet, RegisterServlet

### 2.3 Data Access Layer

**DBUtil.java:** 공유 연결 헬퍼
- 정적 `getConnection()` 메서드
- UTF-8 인코딩, SSL 미사용
- 공개 키 검색 허용

**Database:** MySQL 8.x
```
tables: users, assets, reservations, asset_transfer, 
        asset_disposal, professors, prof_subjects, prof_skills
```

## 3. 인프라 & 배포

### 3.1 하드웨어

- **웹 서버:** Apache Tomcat 9.x
- **데이터베이스:** MySQL 8.x (localhost:3306)
- **개발 환경:** Windows 11

  └─ JDBC Connec tion Pool

   MySQL 8.x (campusnav)

## 4. 보안 아키텍처

### 4.1 인증 & 권한 관리

```
LoginServlet
  ├─ 사용자 인증 (현재: 하드코딩, 개선: DB 조회)
  └─ Session 설정
      ├─ loginUser
      ├─ loginName
      └─ loginRole (6가지 역할)
```

### 4.2 보안 취약점 (현재)

| 취약점 | 심각도 | 대응 |
|--------|--------|------|
| 하드코딩 자격증명 | 🔴 극높음 | DB 연동 필수 |
| SQL Injection 위험 | 🔴 극높음 | PreparedStatement 사용 |
| HTTPS 미적용 | 🔴 극높음 | SSL/TLS 적용 |
| CSRF 미방어 | 🟠 높음 | CSRF 토큰 추가 |
