# 프로젝트 기획서 (Project Charter)

## 1. 프로젝트 개요 (Executive Summary)

### 1.1 프로젝트 명칭
**ICT CampusNav** — ICT폴리텍대학 교내 자원 내비게이션 시스템

### 1.2 프로젝트 개시 배경
- **현황:** ICT폴리텍대학은 8,401개의 교내 자산(강의실, 장비, 공간, 교수 등)을 관리하고 있으나, 사용자가 원하는 자원을 탐색하기 어려움
- **문제점:** 정보 분산, 접근성 저하, 실시간성 부재, 네비게이션 한계, 자원 활용도 저하, 운영 비효율, 데이터 무결성 문제
- **기회:** 통합 데이터베이스 기반의 웹 플랫폼으로 학생, 교수, 연구자의 효율성을 높이고, 행정 부담을 경감

### 1.3 프로젝트 목표 (Objectives - SMART)

| # | 목표 | 설명 | 성공 지표 |
|----|------|------|----------|
| **1** | 교내 자원 통합 검색 플랫폼 구축 | 8,401개 자산을 단일 검색창에서 조회 가능 | 검색 응답시간 < 2초, 정확도 > 95% |
| **2** | 맞춤형 추천 서비스 제공 | 사용자 유형/목적 기반 자동 추천 | 추천 클릭률 > 30% |
| **3** | 실내외 연계 네비게이션 기능 | GPS 및 플로어맵 기반 경로 안내 | 네비게이션 사용률 > 40% |
| **4** | 데이터 기반 운영 효율 개선 | 공간 이용 현황 분석/시각화 | 자원 활용도 측정 및 보고 가능 |

## 2. 스코프 및 범위 (Scope Statement)

### 2.1 프로젝트 스코프 (In Scope)

**데이터:**
- 자산(assets): 8,401개 자원 정보
- 예약(reservations): 자산 예약/이용 현황
- 이관(asset_transfer): 자산 이동/이관 이력 (141건)
- 폐기(asset_disposal): 자산 폐기 기록 (2,721건)
- 교수(professors): 교수 정보 및 전공/기술 태그
- 사용자(users): 역할별 사용자 관리

**기능:**
- 인증 및 역할 기반 접근 제어 (6가지 역할)
- 자산 검색 및 필터링 (키워드, 카테고리, 상태, 위치)
- 자산 상세 정보 조회 (예약 현황, 이관 이력 포함)
- 예약 관리 (실시간 중복 체크)
- 이관/폐기 이력 조회
- 플로어 기반 네비게이션 (기본)
- 교수 정보 및 전공/기술 검색

**기술:**
- JSP + Java Servlets
- Apache Tomcat 9.x
- MySQL 8.x
- Bootstrap 5.3.3 + Bootstrap Icons
- JavaScript (AJAX)

### 2.2 제외 사항 (Out of Scope)

| 항목 | 이유 | 대안 |
|-----|------|------|
| GPS 기반 실시간 경로 안내 | 모바일 개발 필요, 리소스 부족 | Phase 2에서 모바일 앱으로 추진 |
| 사용자 리뷰/평점 | 커뮤니티 기능 추가 필요 | Phase 2에서 추가 |
| 머신러닝 기반 추천 | 데이터/모델링 비용 | Phase 2에서 기본 필터링으로 시작 |
| 다언어 지원 | 한국어 사용자 중심 | Phase 2에서 영문 추가 |
| 모바일 네이티브 앱 | 웹 기반 반응형으로 우선 | Phase 2에서 모바일 앱 개발 |
