```

```

4. 예약 → 확인 메시지
```

## 3. 테스트 케이스 (예시)

```
입력: userid=student, password=1234
기대: 세션 생성 + main_student.jsp 리다이렉트
검증: loginRole == 'student'
```

### TC-002: 검색
```
입력: keyword="강의실", category="강의실"
기대: 검색 결과 20개 이내
검증: 모든 결과가 강의실인지 확인
