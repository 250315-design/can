# 🧭 Campus AI Navigator

## 👥 팀 구성
- **팀장**: 박승순  
- **팀원**: 권동해, 이수혁, 원태연  

---

## 📌 프로젝트 개요
교내 자원을 통합 관리하고, AI 기반 검색 및 실내 네비게이션을 통해  
학생과 연구자에게 최적의 공간과 장비를 빠르게 안내하는  
**스마트 캠퍼스 플랫폼 구축 프로젝트**

---

## 📖 1. 배경 및 이슈

- 교내에 강의실, 연구실, 세미나실, 연구 장비, 교수 연구분야 등 다양한 자원 존재
- 자원 정보가 여러 시스템과 문서에 분산되어 있음
- 자원 접근성이 낮아 원하는 공간 및 장비 탐색에 시간 소요
- 실시간 공간 이용 현황 파악 불가
- 유휴 공간 발생 및 자원 활용도 저하
- 복잡한 건물 구조로 인해 실내 위치 안내 한계 존재
- 사용자 편의성 저하 및 운영 비효율 발생

---

## 💡 2. 해결 방안

- 시설 정보, 연구 정보, 공간 데이터를 **통합 데이터베이스(DB)**로 구축
- 사용 목적 입력 시 **AI 기반 추천 시스템**을 통해 적합한 자원 자동 제안
- **GPS 기반 실내 네비게이션**으로 현재 위치 → 목적지 최적 경로 제공
- 공간 이용 데이터 분석을 통한 **운영 효율 향상**
- 관리자 기능 포함한 통합 관리 시스템 구축

---

## 🎯 3. 프로젝트 목표

### 1) 교내 자원 통합 검색 플랫폼 구축
- 모든 자원 정보 통합 관리 (강의실, 연구실, 장비 등)
- 시설/연구/공간 데이터 통합 DB 구축
- 단일 검색창 기반 통합 검색 제공
- 위치, 목적, 이용 가능 여부 기반 필터링
- 직관적인 UI/UX 설계

### 2) 맞춤형 추천 서비스 제공
- 사용자 유형: 학생 / 연구자 구분
- 사용 목적 기반 자동 추천
- 상황별 추천 (스터디, 연구, 세미나 등)
- 위치, 이용 가능 시간, 관리자 정보 제공
- 데이터 기반 추천 정확도 개선

### 3) 실내외 연계 네비게이션 기능
- GPS 기반 현재 위치 인식
- 건물 외부 → 내부까지 경로 안내
- 최단/최적 경로 탐색 알고리즘 적용
- 층간 이동 (엘리베이터, 계단) 안내
- 시각적 UI 기반 경로 안내

### 4) 데이터 기반 운영 효율 개선
- 공간 이용 데이터 수집 및 분석
- 유휴 공간 시각화
- 장비 사용 현황 관리
- 예약 데이터 기반 운영 최적화
- 관리자 의사결정 지원

---

## 🛠️ 4. 세부 내용

### 1) 통합 데이터베이스 설계
- 자원 데이터 표준화
- 건물/층/호실 구조 설계
- 자원 속성 정의 (위치, 수용 인원, 장비 등)
- 실시간 이용 가능 여부 반영
- 확장 가능한 구조 설계

### 2) 통합 검색 및 필터링
- 키워드 기반 검색
- 위치 기반 정렬
- 목적별 검색 옵션
- 예약 가능 여부 필터링
- 상세 정보 페이지 제공

### 3) AI 추천 시스템
- 사용자 유형 기반 추천
- 목적 입력 → 자원 매칭 알고리즘
- 이용 빈도/선호도 반영 구조
- 수용 인원 및 적합도 고려
- 추천 우선순위 정렬

### 4) 네비게이션 시스템
- GPS 기반 위치 수집
- 캠퍼스 지도 연동
- 최적 경로 탐색 알고리즘
- 층간 이동 경로 포함
- 단계별 시각적 안내

### 5) 관리자 및 예약 시스템
- 자원 CRUD 기능
- 장비 상태 및 유지보수 관리
- 예약 및 승인 시스템
- 실시간 사용 현황 업데이트
- 관리자 권한 분리

### 6) 공간 이용률 분석
- 시간대별 이용 데이터 수집
- 유휴 공간 분석 및 시각화
- 장비 사용 빈도 분석
- 월별/학기별 리포트 생성
- 데이터 기반 운영 개선 지원
