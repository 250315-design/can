# 기능 분해도 (Function Decomposition Map)
## CampusNav - ICT폴리텍대학 캠퍼스 자원 통합 네비게이션 시스템

**프로젝트명:** ICT CampusNav  
**버전:** v1.0  
**작성일:** 2026-05-20  
**방법:** 역공학 기반 기능 추출 (기획서 기반 매핑)

## 1. 전체 기능 분해도 (WBS - Work Breakdown Structure)

```
ICT CampusNav 시스템
│
├─ 1. 사용자 관리 (User Management)
│  ├─ 1.1 인증 (Authentication)
│  │  ├─ 1.1.1 로그인 (학생/조교/교수/관리자/게스트/외부인)

│  │  ├─ 1.1.3 회원가입 (자체 등록)

│     ├─ 1.2.2 역할별 기능 활성화/비활성화

├─ 2. 자원 검색 & 조회 (Asset Search & Retrieval)

│  │  │  └─ 이전 부서 → 이후 부서
│  │  └─ 2.2.3 향후 예약 현황 표시
│  │     ├─ 예약된 시간대 표시
│  │     ├─ 예약자, 목적, 시간 표시
│  │     └─ 현재 이용 가능 여부 표시
│  │

│     └─ 2.3.3 결과 캐싱 (향후)
```

## 2. 주요 기능 우선순위 (Priority & Phasing)

### 2.1 Phase별 기능 배치

#### **Phase 1: MVP (최소 기능 제품) - 1개월**
```
현재 구현 상태 안정화 + 보안 패치

1.1 인증 → DB 연동 (LoginServlet 수정)
1.2 접근 제어 → 강화
2.1 통합 검색 → 최적화
2.2 상세 조회 → 유지
2.3 검색 최적화 → 인덱싱 추가
3.1 예약 생성 → 강화
3.2 예약 조회 → 유지
3.4 예약 취소 → 유지
4.1 자산 이관 → 유지
4.2 자산 폐기 → 유지
5.1 교수 정보 → 유지
11.4 모니터링 → 기본 구현
11.5 로그 관리 → 구조화된 로그
```

#### **Phase 2: 핵심 기능 (Core Features) - 3개월**
```
기획서 목표 중 미구현 기능 추가

7.1 캠퍼스 지도 (Naver Map API 연동)
7.2 실내 네비게이션 (기본)
8.1 사용 목적 기반 추천
8.2 사용자 유형별 추천
8.3 인기도 기반 추천
6.1~6.5 자산 관리 완성
9.1 관리자 대시보드 (기본)
9.2 리포트 생성 (기본)
```

#### **Phase 3: 확대 (Enhancement) - 6개월**
```
사용자 경험 고도화

10.1 예약 관련 알림
10.2 시스템 알림
3.3 예약 수정
6.4 자산 일괄 등록
9.3 차트 & 시각화
11.2 데이터 관리 (백업)
```
